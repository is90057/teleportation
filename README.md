# 瞬間移動 · 攝影機特效工具

以 **Python + PyQt6 + OpenCV + MediaPipe** 實作的即時攝影機特效程式。

## 功能

- **攝影機啟動 / 停止**：可選擇裝置編號，即時預覽（鏡像）。
- **空景圖拍攝**：可設定倒數秒數，倒數結束自動拍下空景圖並存到 `captures/`。
- **MP4 錄影**：錄下「含特效的最終畫面」，輸出至 `captures/recording_*.mp4`。
- **特效 — 瞬間移動**：啟用後，當鏡頭偵測到人物以**食指與中指併攏指向額頭眉心**，即進入傳送模式，人物會如星艦迷航般逐渐分解為光點並消失，停留在空景，可按「重置人物」還原。

## 安裝

```bash
pip install -r requirements.txt
```

MediaPipe 模型已隨專案放在 `models/`，可離線使用：

- `hand_landmarker.task`：手部關鍵點偵測
- `selfie_segmenter.tflite`：人物分割

## 執行

```bash
python main.py
```

## 使用流程

1. 點「啟動攝影機」。
2. （選配）設定倒數秒數後點「拍攝空景圖」，倒數期間請離開畫面 — 特效需要這張空景圖。
3. 點「開始錄影」可記錄含特效的最終畫面。
4. 勾選「啟用特效」並選擇「瞬間移動」，可調整消散秒數。
5. 對鏡頭做出「食指 + 中指併攏指向眉心」手勢，即觸發傳送消散動畫。
6. 動畫完成後人物保持消失，按「重置人物」讓人物重新出現。

```

├── main.py                 # 程式進入點
├── requirements.txt

├── captures/               # 空景圖與錄影輸出（執行時自動建立）
├── core/
│   ├── config.py           # 常數設定
│   ├── vision.py           # 人物分割 + 手勢偵測
│   ├── effects.py          # 瞬間移動消散特效
│   └── camera.py           # 攝影機背景執行緒 + 錄影
└── ui/
    └── main_window.py      # PyQt6 介面
```
